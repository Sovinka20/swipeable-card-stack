## 🛠 Текущий стек и особенности

- **Данные:** 160 направлений, парсинг `results.json`, фото из `public/scenario_output/`.
- **Библиотеки:** Next.js, Tailwind CSS, Framer Motion, lucide-react.
- **Стили:** Основные повторяющиеся классы (стекло, панели, пункты меню) вынесены в `globals.css` (компоненты `glass-btn`, `sidebar-panel` и т.д.).
- **Известные ограничения на текущий момент:** Избранное хранится только в памяти (сбрасывается при перезагрузке страницы), реального роутинга между страницами еще нет (только экран свайпов).

## 🚦 Статус: MVP (Функциональный прототип)

### Реализованный функционал:

1. **Карточка:** Темный UI, скругления 28px, картинка сверху (52%), плавный градиент в `#1a1a1a`.
2. **Механика свайпа:** Перетаскивание через `drag="x"` с порогом 100px.
3. **Кнопки на карточке:** "Не сейчас" (серая) и "Это моё" (белая с красным сердцем).
4. **Анимации реакций:** Большое зеленое сердце при лайке, красное разбитое сердце при отказе.
5. **Избранное:** Кнопка-звезда в правом верхнем углу. При клике меняет заливку на желтую, но **не листает карточку**.
6. **Данные:** Автоматический парсинг 160 объектов из `results.json`.

### Известные ограничения:

- **Описания:** Текст описания генерируется автоматически (`{card_type} — твое следующее приключение...`), так как в JSON нет готовых русских текстов для каждого города.
- **Избранное:** Список избранного хранится в памяти (`useState`), при перезагрузке страницы сбрасывается.
- **Цикличность:** После 160-й карточки приложение возвращается к первой.
