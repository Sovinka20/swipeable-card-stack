# История изменений

Все заметные изменения в проекте будут документироваться в этом файле.  
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),  
проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

---

## [0.0.2] - 2026-10-01

### Добавлено
- **Zustand** для глобального состояния: язык, тема, избранное, текущий индекс карточки. С `persist`-middleware — состояние сохраняется в localStorage.
- **Мультиязычность данных карточек**: переключение RU/EN в шапке. Карточки подтягиваются из `locales/data/ru.json` и `locales/data/en.json`.
- **Фиксированная высота контейнера текста** на карточке (170px) — устранено «прыгание» текста при смене карточки.
- **Динамический фон** — размытая копия текущей карточки с плавным кроссфейдом (было в 0.2.0, но теперь стабилизировано).

### Изменено
- **Градиент затемнения** снизу карточки усилен: `h-4/5`, `from-black via-black/90 to-transparent`.
- **Анимация появления карточки**: убран `scale`, оставлен только `opacity`, чтобы текст и кнопки не дёргались.
- **`AnimatePresence`** переключён с `mode="popLayout"` на `mode="wait"` — старая карточка уходит до появления новой.
- **Тайминг свайпа** синхронизирован с анимацией exit: 350ms.
- **Структура данных**: `results.json` переименован в `locales/data/ru.json`, добавлен `locales/data/en.json`.
- **Кнопка «Отмена»** теперь работает через стор (`prevCard`).

### Исправлено
- Текст на карточке больше не «прыгает» при перелистывании.
- Layout карточки стабилен при разной длине заголовка и описания.
- Избранное сохраняется между сессиями (localStorage).

### Известные ограничения
- Интерфейсные тексты (меню, кнопки, подписи) пока на русском — не вынесены в i18n.
- Нет автотестов.
- Демо-набор данных ограничен (~20 карточек вместо полного набора).

## [0.0.1] - 2026-09-08

### Улучшение визуала интерфейса
- Улучшен градиент: добавлен плавный переход цветов от изображения к тексту карточки (blur-эффект и оверлей).
- Улучшен фон: реализован динамический фон из размытой копии текущей карточки с плавным кроссфейдом при перелистывании.
- Улучшены анимации (3х):
  - **Отмена:** разбитое черное сердечко с анимацией вылета влево.
  - **Согласие:** красное сердечко с искрами и анимацией вылета вправо.
  - **Избранное:** плавное переключение звезды (заливка/прозрачность) без сброса карточки.

### Работа с контентом
- Добавлена возможность мультиязычности: кнопка переключения языка интерфейса (RU/EN) в верхней панели.
- *Ожидает реализации:* поле "Название местности".
- *Ожидает реализации:* поле "Описание местности".

### Техническое расширение
- Реализован роутинг и навигация (кнопки слева и справа невидимые, работают как зоны для свайпа).
- Добавлено плавающее боковое меню (сайдбар) с возможностью разворачивания/сворачивания.
- Добавлена поддержка цветовых тем (День / Ночь) с переключателем в меню.

### Добавлено

- Инициализация проекта и базовая структура Next.js.
- Создание полноэкранного тёмного интерфейса (bg-black).
- Реализация карточки путешествий (размер 380x580, скругления, шрифт Inter).
- Добавление кнопок действий внутри карточки ("Не сейчас" и "Это моё").
- Реализация свайпа карточек с анимацией вылета (Framer Motion).
- Добавление анимаций-реакций (зеленое сердце и разбитое сердце).
- Добавление кнопки "Избранное" (звезда в правом верхнем углу, работает без листания).
- Интеграция с локальным файлом `results.json` (160 городов).
- Удаление всех посторонних UI-элементов (панелей и меню) для чистого отображения карточек.
